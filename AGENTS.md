# Working on crosshair-bench

`crosshair-bench` (`TheGustafson/crosshair-bench`) is the match harness, single-turn tactical benchmark, and Elo rating pipeline for `/blog/llms-vs-crosshair` in the sibling `../private-blog` repository.

## Core Rules

1. **Never commit API keys or secrets.**
   - OpenRouter credentials live exclusively outside all Git repositories at `~/.config/crosshair-arena/openrouter.env` (`chmod 600`) or in the `OPENROUTER_API_KEY` environment variable.
   - `.gitignore` blocks `.env*`, `*.key`, `*secret*`, and `*credentials*`. Never weaken those rules.
2. **Never lose a single turn of paid LLM data.**
   - `crosshair_bench/match_runner.py` writes an atomic per-ply checkpoint to `results/checkpoints/<match_id>.partial.json` (`os.replace` from `.tmp`) after every turn, and appends every LLM turn immediately to `results/turns_log.jsonl`.
   - When a match finishes (`win` or `forfeit`), it is written atomically to `results/matches/<match_id>.json` and its `.partial.json` checkpoint is deleted.
   - Re-running `run_match` or `run_batch` automatically skips completed matches in `results/matches/` and resumes any interrupted match in `results/checkpoints/` from `len(match_doc["moves"])`.
   - Never pass `--overwrite` on paid LLM batches unless intentionally re-running a specific match.
3. **Use the canonical roster and deterministic manifests.**
   - `crosshair_bench/roster.py` is the single source of truth for the 5-company, 20-LLM-entrant + 4-engine roster and balanced 2-ply opening book.
   - `crosshair_bench/build_manifests.py` generates all deterministic batch manifests under `manifests/`. Do not hand-edit generated manifest JSON files.

## Common Commands

```bash
# Regenerate all deterministic batch manifests in manifests/
python3 -m crosshair_bench.build_manifests

# Run a batch manifest with concurrent workers and automatic checkpoint resume
python3 -m crosshair_bench.run_batch manifests/batch_00_engine_anchors.json --concurrency 8
python3 -m crosshair_bench.run_batch manifests/batch_01a_vs_uct50.json --concurrency 24
python3 -m crosshair_bench.run_batch manifests/batch_01b_vs_az400.json --concurrency 24
python3 -m crosshair_bench.run_batch manifests/batch_01c_vs_az4000.json --concurrency 24
python3 -m crosshair_bench.run_batch manifests/batch_02_thinking_delta.json --concurrency 24
python3 -m crosshair_bench.run_batch manifests/batch_03_flagship_rr.json --concurrency 24
python3 -m crosshair_bench.run_batch manifests/batch_04_flash_rr.json --concurrency 24

# Recompute anchored BayesElo / Bradley-Terry ratings and move-quality leaderboard
python3 -m crosshair_bench.elo

# Sync completed matches and leaderboard to ../private-blog/src/data/llmArenaGames.json
python3 -m crosshair_bench.sync_blog
```

## Persistence Layout

- `manifests/*.json`: Deterministic batch manifests generated by `crosshair_bench/build_manifests.py`.
- `results/matches/<match_id>.json`: Completed match transcripts with ply-by-ply board states, flips, `az-puct-400` shadow-oracle evaluations, reasoning traces, and OpenRouter telemetry.
- `results/checkpoints/<match_id>.partial.json`: In-progress per-ply checkpoints (automatically resumed on restart and removed upon match completion).
- `results/turns_log.jsonl`: Append-only per-turn ledger of every completed LLM move.
- `results/batches/<batch_id>_status.json`: Live progress, token counts, and cumulative spend for each batch run.
- `results/leaderboard.json`: Anchored Elo and move-quality summary across all completed matches.
